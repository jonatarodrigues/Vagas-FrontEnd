# Vagas-FrontEnd (OpenBoard)

Projeto acadêmico desenvolvido para a disciplina de **Front-End**, no **3º ano do curso de Engenharia de Software**.

## Sobre o projeto

O **OpenBoard** é uma página web de vagas de emprego, com foco em oportunidades de startups de tecnologia. A interface apresenta:

- Seção inicial (hero) com chamada para publicação de vagas;
- Listagem das últimas vagas disponíveis, com informações como empresa, cargo, faixa salarial e modalidade de trabalho;
- Filtros por tipo de vaga (Efetivo, Estágio, Temporário) e por área (Engenharia, Design, Gestão);
- Seção de cadastro para receber novas vagas por e-mail;
- Depoimentos de usuários da plataforma;
- Rodapé com links institucionais.

## Tecnologias utilizadas

- **HTML5** — estruturação da página;
- **CSS3** — estilização e responsividade (layout adaptado para dispositivos móveis);
- **JavaScript** — comportamento e interatividade (em desenvolvimento).

## Estrutura de arquivos

```
├── index.html   # Estrutura da página
├── style.css    # Estilos visuais e responsividade
└── script.js    # Scripts em desenvolvimento
```

## Como executar

Basta abrir o arquivo `index.html` em um navegador, ou utilizar uma extensão como o **Live Server** (VS Code) para visualizar com recarregamento automático.
